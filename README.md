## 🚀 Featured project

### 💈 [CitasBarberia](https://github.com/javiermp96/CitasBarberia)
Full-stack appointment-booking platform for barbershops, with three roles (client, barber, superadmin).

- **Stack:** React 19, TypeScript, Vite, Tailwind CSS v4, Supabase (Auth, PostgreSQL, Realtime)
- Dynamic availability-slot calculation based on service duration, existing appointments and breaks
- Real-time notifications for the barber and email alerts
- Business rules enforced in the database: Row Level Security, triggers and an exclusion constraint against double bookings
- Backed by SQL tests that first reproduce each attack and then verify it fails
